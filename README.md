## Reducing Returns to Improve Net Revenue: Returns/Cancellations Diagnostics & Action Plan (E-commerce)

## Business Goal
Reduce return/cancellation rate

Increase net revenue (gross revenue − return/cancellation impact)

## Source Dataset
Online Retail II--This dataset originates from UCI Machine Learning Respository that includes online retail transactions from 2009-2011.The 'invoice' number beginning with letter 'C' refers to the cancellation proxy.
which is used to approximately represent "post-sale return pressure".It is not equivalent to the entire process of actual returns, but is sufficient for identifying driving factors and optimization opportunities.
